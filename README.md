# Flyrank Workflow Drill - User Settings Form

A lightweight, accessible, and robust User Settings form featuring comprehensive client-side validation built with HTML, CSS, and JavaScript.

## Features
* **Strict Input Validation**: Validates full name formatting, standard email structure, and strict password security parameters.
* **Accessibility Focused**: Fully engineered with semantic markup, dynamic `aria-live` announcements, and automatic cursor focus adjustments for assistive technology.
* **Responsive Card Layout**: A clean, centered modern UI wrapper optimized across multiple device screens.

## Project Structure
* `index.html` - Core structural form components and accessibility attributes.
* `style.css` - Custom design properties, flex layouts, and validation states.
* `script.js` - Validation handlers, programmatic clearing routines, and event tracking.
* `WORKFLOW.md` - Reflective report contrasting rapid versus precise AI-assisted engineering constraints.
* `CLAUDE.md` - Local environment development directives and code structure conventions.
